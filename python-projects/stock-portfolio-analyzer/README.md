# Stock Portfolio Analyzer

This is a beginner Python practice app that analyzes a simple stock and ETF portfolio.

## Purpose

The goal of this project is to practice Python fundamentals while applying them to a real-world financial analysis example.

## Skills Practiced

- Variables
- Lists
- Dictionaries
- Loops
- Functions
- Basic calculations
- Simple financial analysis
- Gain/loss calculations
- Percentage return calculations
- Portfolio allocation calculations

## What the App Does

The script analyzes a small sample portfolio and calculates:

- Cost basis
- Current market value
- Dollar gain or loss
- Percentage return
- Portfolio allocation
- Best-performing holding
- Worst-performing holding
- Total portfolio return

## Files

- `main.py` — Python script for the stock portfolio analyzer

## Notes

This project uses manually entered sample data. It does not use live stock prices and is not investment advice.
