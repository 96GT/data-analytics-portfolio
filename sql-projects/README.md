# SQL Projects

Interactive Codex code for practicing SQL and building a data analytics portfolio.

This folder contains SQL projects and practice work focused on turning raw data into useful business insights.

## Projects

### Beginner Practice

Folder: `beginner-practice`

A starter area for practicing core SQL concepts, including:

- `SELECT` statements
- Filtering data
- Aggregations with `SUM` and `COUNT`
- Grouping results
- Sorting query output

### Superstore Sales Analysis

Folder: `superstore-sales-analysis`

A beginner sales analysis project using a Superstore-style dataset. The current query analyzes total sales by product category.

## Skills Practiced

- Writing readable SQL queries
- Summarizing sales data
- Grouping and ordering results
- Building portfolio-ready analysis examples
- Documenting project purpose and results
